Кварц Черный



Название команды: RobloxTOP



Описание проекта:

Команда RobloxTOP работает над проектом Кварц Черный.

Участники команды совместно разрабатывают проект

и используют GitHub для хранения и отслеживания изменений.



Цель проекта:

Организовать совместную разработку с использованием

системы контроля версий Git и удалённого репозитория GitHub.


## Структура проекта

Проект представляет собой мод для Minecraft 1.21.1 (Fabric).

- `src/main/java` — исходный код на языке Java. Класс точки входа `com.robloxtop.BlackQuartzMod` вызывается загрузчиком Fabric при старте игры.
- `src/main/resources` — ресурсы и конфигурация: файл `fabric.mod.json` (описание мода, точки входа, зависимости), каталоги `assets` и `data`.
- `build.gradle` и `gradle.properties` — конфигурация сборки Gradle и плагина Fabric Loom.
- `gradle/wrapper` — файлы Gradle Wrapper для единой версии системы сборки.
- `build` — продукты сборки (JAR-файл мода), не включается в Git.

## Игровой объект

Блок «Черный кварц» (black_quartz_block) — декоративный строительный блок из кварца Нижнего мира.
Не излучает свет, не горит в лаве, устойчив к взрывам.
